Educational prototype, not a design tool. Hoop stress uses the closed-form Kirsch solution for a circular opening in a biaxial far-field stress with internal pressure; rock mass strength uses a Hoek–Brown-derived reduction of intact UCS by GSI. Hydraulic-jacking limit state uses the classical minimum-principal-stress cover criterion. Independent normal variates, no spatial correlation. Benchmark against numerical models (FEM/FDM/DEM) and site data before any design use — exactly the validation gap the KORVA project is built to close.
